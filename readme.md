# AI Scans Reader (0.1)

## Стек

.NET 10, ASP.NET Core Web API
Ollama (локально), модель qwen3-vl:8b-instruct
FileSystemWatcher, BackgroundService, DI, IOptions
Swashbuckle.AspNetCore для Swagger

## Описание

Сервис извлекает структурированные данные из сканов типового кадрового документа (форма Т-1 «Приказ о приёме на работу») с помощью локальной ИИ-модели Ollama (Qwen3, instruct-версия).
Следит за папкой со сканами. При добавлении новых файлов отправляет их поочерёдно в модель для извлечения данных.

## Что извлекается

ФИО (одной строкой плюс разбивка на фамилию, имя, отчество), табельный номер, организация, номер и дата документа, подразделение, должность, дата приёма, оклад, характер работы, испытательный срок.

## Как работает

1. При старте загружает все PNG из папки и проверяет кэш (scans_json) по SHA256. Уже обработанные файлы повторно в модель не отправляются.
2. FileSystemWatcher отслеживает добавление, изменение и удаление файлов.
3. OllamaService берёт из контейнера следующий файл со статусом NotSent, отправляет его в Ollama, получает JSON по схеме и нормализует данные: даты приводятся к dd.MM.yyyy, оклад очищается от пробелов, испытательный срок приводится к формату N месяц(ев).
4. Результат сохраняется в scans_json/<имя>.json, в bench/benchmark.json обновляется минимальное, максимальное и среднее время обработки.
5. В консоль выводится прогресс и расчётное время до конца обработки.

## API

GET /api/scans — все сканы, фильтр ?status=NotSent|Sent|ResultReceived.
GET /api/scans/completed — только готовые результаты.

Swagger: https://localhost:7229/swagger

## Качество извлечения

Первые версии промпта давали нестабильный результат: модель возвращала данные в свободной форме, путала порядок слов в ФИО, писала даты в разных форматах, оставляла служебные пометки из бланка.
В ходе работы промпт и JSON-схема дорабатывались: добавлены жёсткие правила форматирования, примеры и ограничения на поля.

В финальной версии на датасете из 100 сканов Т-1 модель возвращает ожидаемый результат:
ФИО одной строкой в порядке из документа плюс разбивка на фамилию, имя, отчество; даты в едином формате dd.MM.yyyy; оклад только цифрами, без пробелов и разделителей; испытательный срок в едином формате N месяц(ев); кавычки в названии организации в виде «...» вместо прямых.

Если в исходном документе ФИО записано в нестандартном порядке (Имя Отчество Фамилия), модель копирует это как есть. Код не исправляет документ, чтобы не искажать исходные данные.

## Ограничения

Не обрабатывает несколько документов на одном изображении.
Требует локально запущенную Ollama с моделью qwen3-vl:8b-instruct.
Время обработки одного скана составляет 15–30 секунд на GPU 8 ГБ и зависит от размера изображения.
Обработка последовательная, без параллелизма: пачка файлов в одном запросе не помещается в контекст.
Если в документе ФИО перепутано местами, модель копирует это как есть. Код не исправляет документ.

## Запуск

1. Выполнить `ollama pull qwen3-vl:8b-instruct`.
2. Настроить пути в appsettings.json:

```json
{
  "Scans": {
    "InputFolder": "path/to/scans",
    "JsonResultsFolder": "path/to/results",
    "BenchFolder": "path/to/bench"
  },
  "Ollama": {
    "BaseUrl": "http://localhost:11434",
    "Model": "qwen3-vl:8b-instruct",
    "TimeoutMinutes": 5
  }
}
